KV bytes per token come from each model's config.json at a pinned commit (layers × KV heads × head size × 2 × bytes). Weights are an estimate: parameters × bytes per parameter (Q4 ≈ 0.6, Q8 ≈ 1.07, FP16 = 2). Usable memory = GPU memory − 0.3 GiB for compute buffers. Measured tiles show the measured result (RTX 3050 Laptop 6 GB, llama.cpp). Dotted tiles use sliding-window or mixed layers, so the config alone can't give a per-token KV figure.
