How it's calculated

calls = requests/day × days × (1 + retries)
input billed = input tokens × (1 − trimmed)
cost per call = input billed × ((1 − cached) × price_in + cached × price_in × cached multiplier) + output × price_out
bill = calls × ((1 − small share) × cost on main + small share × cost on small) ÷ 1,000,000

One request type with average token counts. Output tokens and retries are assumed to stay the same per call when you trim or route. Estimate, not a quote.
